# Maji-Track 🌊
**Nairobi Water Access & Shortage Monitoring Platform**

Maji-Track is a web platform dedicated to tracking regions in Nairobi experiencing water shortages, splitting the city into districts where residents submit shortage reports and admins verify them[cite: 12].

## Key Features
* **Landing Page**: Features a critical water shortage banner and navigation buttons routing to Login and Sign Up pages[cite: 12].
* **Districts & Severity Sorting**: Sorts shortages from most critical down to least critical (e.g., *Location: Umoja 1, Severity: Critical, Time-Without-Water: 3 Weeks*)[cite: 12].
* **Resident & Admin Dashboards**: Resident dashboard shows district shortages and report submission tools; Admin dashboard shows pending and approved reports with a route to the resident view[cite: 12].

## Setup Instructions
1. Clone the repository: `git clone https://github.com/Pxffy123/Maji-Track.git`
2. Navigate to frontend: `cd Maji-Track/MajiTrackFrontEnd`
3. Install dependencies & run: `npm install && npm run dev`

See `docs/QA_CHECKLIST.md` for the complete frontend testing checklist[cite: 13].
